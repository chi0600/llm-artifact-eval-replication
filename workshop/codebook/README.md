# Reviewed descriptive codebook (redacted public version)

`codebook_41_definitions_public.csv` contains the descriptive code IDs, names, categories and definitions from the **41-code human-reviewed summary**, without transcript text or segment-level evidence.

The first **30 codes** originated in the initial codebook. For those codes, the originally recorded inclusion and exclusion rules are included. The **11 additional codes** were introduced during the manual review process; the available summary does not supply matching formal inclusion/exclusion rules for these codes, so those cells are **left empty**, not inferred.

The file deliberately omits:
- example/supporting statement IDs;
- segment counts, unique speaker counts and workshop interaction-context combinations;
- transcript quotations, participants and organizational metadata.

This redacted codebook helps inspect the coding vocabulary, but it is **not sufficient to reproduce the qualitative coding decisions, E1–E8 support thresholds or the inductive synthesis**. The underlying reviewed corpus and mapping remain restricted. See [Data availability](../../DATA_AVAILABILITY.md).

For methodology, consult the accompanying manuscript's Data Analysis and Threats to Validity sections.
